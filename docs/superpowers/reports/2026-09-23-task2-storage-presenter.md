# Task 2: 保存と表示モデル

## 実装

- 保存キーを `moonlight-idle:v1` に切り替え、保存形式を `{ version: 1, game }` にした。外側に未知フィールドを持つデータも受け入れない。
- `createDefaultSave(now)` は指定時刻を `game.lastUpdatedAt` に持つ初期ゲームを返す。
- 読込・書込の両方で保存構造と `isGameState` を検証する。壊れたJSON、未知バージョン、負数や有限でない状態は初期状態へ戻し、無効な状態は書き込まない。
- 読込と書込時のストレージ例外は従来と同じ形式の結果オブジェクトで通知し、ゲーム処理を例外で止めない。
- 旧キー `moonlit-sorting-office:v1` にはアクセスせず、削除もしない。
- `toViewModel(game)` は資源と生産量の数値・日本語表示、設備・強化の費用、所持数、解放状態、購入可否、星屑欄の解放、転生条件・記憶獲得数・転生後倍率を返す。大きな値は万・億・兆などで短縮する。

## TDD の証拠
