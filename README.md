# 月影工房

月光を集め、夜空の設備を育てていく日本語のインクリメンタルゲームです。最初は大きなボタンを押し、やがて設備の自動生産と星屑、転生による恒久強化へ進みます。ゲームの進行はブラウザ内だけで完結します。

## 起動

Node.js 20以降を用意し、リポジトリ直下で静的サーバーを起動してください。

```bash
python -m http.server 4173
# http://localhost:4173/
```

## 遊び方

- 「月光を集める」を押すと月光が増えます。
- 月光でランタン、観測机、月輪塔、夜空庭園を購入すると、自動で月光を生産します。購入した設備の台数に応じて次の価格が上がります。
- 月光を集めるとクリック強化や設備強化が順に解放されます。
- 周回で月光を5,000集めると星屑と星屑凝縮器が解放されます。凝縮器は月光10,000で購入でき、星屑を生産します。
- 月光を100,000以上、星屑を周回累計25以上集めると転生できます。転生前に、リセットされるものと得られる記憶の効果を確認画面に表示します。確定後は月光、星屑、設備、強化、周回累計が初期化され、記憶による恒久倍率と総転生数は残ります。
- ブラウザを閉じている間も最大8時間分の収益を受け取れます。戻ったときに獲得量が表示されます。

## 保存とオフライン利用

進行状況はこのブラウザの同じoriginにある `localStorage` の `moonlight-idle:v1` に保存されます。操作後と一定間隔で保存し、画面を離れるときにも保存します。保存できない環境でも、現在のタブでは遊び続けられます。別の端末やブラウザとは同期しません。

前作の保存キー `moonlit-sorting-office:v1` は読み込みも削除もしません。ソースやService Workerを更新しても、保存済みのゲームデータは移行・置換されません。端末のサイトデータを削除すると、このブラウザの進行状況も削除されます。

## GitHub PagesとiPhone

公開URLは `https://jueyuedao-ship-it.github.io/moonlit-sorting-office/` のままです。HTML、manifest、Service Worker、モジュール、アイコンは相対URLで参照し、リポジトリのサブパスでの配置を前提にしています。

iPhone Safariでは、URLを開く → 共有 → 「ホーム画面に追加」 → 追加されたアイコンから一度オンラインで起動、の順に進めてください。初回のアプリ読み込み後はオフラインでも遊べます。更新時はオンラインで開き直し、更新通知が表示されたら再読み込みしてください。
