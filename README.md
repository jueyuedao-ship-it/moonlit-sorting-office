# 月影仕分け局

深夜の航路郵便を、規則帳に従って三つの行き先へ仕分けるローカルファーストの作業ゲームです。

## 起動

```bash
python -m http.server 4173
# http://localhost:4173/
```

## 操作

- `1`: 特急便
- `2`: 確認台
- `3`: 通常便
- 画面のボタンも利用可能

赤印は特急便、それ以外で現在の要確認地区または重量なら確認台、その他は通常便です。18通を処理するか、3回誤配すると勤務終了になります。

## 保存と更新

進行中の勤務・勤務結果・最高得点・累計勤務数は、このブラウザの同じoriginにある端末内ストレージへ各操作後に保存します。保存できない環境でもゲームは続けられますが、ヘッダーに状態を表示します。保存データは端末・ブラウザ・originごとに独立しており、GitHub上のソースやService Workerを更新しても、すでに保存された勤務データは移行・置換・削除されません。サイトデータを削除した場合や別端末では別の保存領域になります。
